# 고객이 늙은 상권일수록, 가게는 닫히지도 새로 열리지도 않는다

*[English README](README.md)*

부산의 고령 상권은 **신진대사가 멈춘 상태**입니다. 가게가 닫히지도, 새로 열리지도 않습니다.
그런데 닫힘만 세는 지표는 이 상태를 '안정'으로 읽습니다. 여기가 사각지대입니다.

**2026 부산 빅데이터 활용 공모전** (분석·시각화 부문) 출품작.
분석은 부산 데이터 오픈랩에 3회 방문해 내부에서 수행했고, 아래 수치는 모두 오픈랩 반출 심사를
통과한 산출물에서 나온 값입니다.

![시각화 1장](제출자료/1_시각화/시각화_1장_최종.png)

## 데이터가 말한 것

이 프로젝트는 다른 가설에서 출발했습니다 — **비용 압박이 가맹점 소멸을 예측한다**.
데이터는 이 가설을 지지하지 않았습니다. 대신 드러난 것이 신진대사 문제였습니다.

| 질문 | 결과 |
|---|---|
| 비용 압박(MPI)이 가맹점 소멸을 예측하는가 | **지지되지 않음** |
| 상권 위기 판정에 사각지대가 있는가 | **있음** |
| 고령 상권의 신진대사는 어떤 상태인가 | **포착** — 소멸도 신규도 모두 낮음 |

부산 16개 구·군에서, 60세 이상 고객의 결제액 비중은 두 신진대사 지표 모두와 반대로 움직입니다.

- 가맹점 소멸률 — Spearman **ρ = -0.61**
- 신규 개점률 — Spearman **ρ = -0.55**

가맹점 수를 통제한 편상관에서도 부호가 유지되고(-0.68 / -0.66), 구·군을 하나씩 빼는
민감도 검정에서도 부호가 살아남습니다.

**5개 구**(중구·서구·영도구·사상구·사하구)가 두 지표 모두에서 중앙값 아래에 있습니다.
닫힘만 보는 지표는 이곳을 안정으로 부르지만, 신진대사로 보면 정체 상권입니다.
동구는 반례로 의미가 있습니다 — 고객층이 가장 고령인데도 신규 개점은 높습니다.
한 축만 보는 판정이 부족한 이유가 바로 이것입니다.

## 방법

**비용 압박 지수 (MPI)** = 매입 ÷ 매출. 업종 대분류별로 표준화해 구·군의 업종 구성이
순위를 좌우하지 않도록 보정했습니다 (순위 보존 r = 0.776).

**신진대사 지표**
- 소멸률 = 35개월간 BC카드 가맹 종료 가맹점 ÷ 기존 가맹점
- 신규 개점률 = 신규 개점 가맹점 ÷ (기존 + 신규)

**통계** — Spearman 순위상관 (비모수, n = 16), 민감도 분석, 순열검정.

## 수치를 인용할 때

- **"가맹점 소멸"은 "폐업"이 아닙니다.** BC카드 가맹 계약이 종료된 것으로, 행정상 폐업의
  대리 지표입니다. 보고서 전체가 전자를 쓰며, 인용할 때도 그래야 합니다.
- **상관은 탐색적 신호입니다.** n = 16이고, 36개 변수쌍을 탐색하는 과정에서 나온 값입니다.
  다중검정 보정(Bonferroni·FDR)에서는 확증 수준에 이르지 않습니다 — 네 겹의 강건성을 갖는
  *방향* 가설로 보고할 뿐 확증된 효과가 아닙니다. 동반 변동을 기술할 뿐 인과 주장이 아니며,
  인과로 바꿔 서술하면 안 됩니다.
- **구·군별 고령 비중**은 `out7`만 인용합니다. `out3`은 산출 기간이 달라 서로 대체할 수 없습니다.
