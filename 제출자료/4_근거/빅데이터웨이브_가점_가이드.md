## 2. 실행 순서 (캡처 3장이 목표)

1. **회원가입 + 로그인** (data.busan.go.kr)
2. **데이터 ① 다운로드** — 상세 페이지 FILE 탭 → `일별 행정동 연령 소비매출 월별 일평균.XLSX` 다운로드. **다운로드 직후 상세 페이지 화면 캡처** (데이터명+로그인 상태 보이게) → 캡처 1
3. **데이터 ② 다운로드** — `부산광역시_지역화폐(동백전) 가맹점 현황_20260424.CSV` 동일 방식 → 캡처 2
4. **브라이텍스 사용** — 데이터 분석 > 셀프 분석 > **분석 서비스 실행** → (새 창, 안 뜨면 새로고침 2~3회) → `Create New Project` (이름 예: `busan_aging_market`) → 데이터 ① XLSX를 Load → 차트 하나 생성 (예: 행정동별 '60대이상' 월별 일평균 이용금액 막대, 또는 연령별 합계 비교) → **프로젝트명 + 분석 플로우 + 차트가 한 화면에 보이게 캡처** → 캡처 3 ★붙임4가 요구하는 "브라이텍스 사용결과 캡처"가 바로 이것
5. 캡처 3장을 `제출자료/4_근거/웨이브_캡처/` 폴더에 저장 (예: `웨이브1_연령소비매출_다운로드.png`)
6. 받은 원본 2개 파일을 `제출자료/3_활용데이터/`에 복사 (활용데이터 동봉 — 서식이 추가 활용 데이터 기재·제출을 요구)
7. **다운로드한 XLSX·CSV를 진세운에게(또는 Claude 세션에) 전달** → 구군 집계·교차 확인 계산은 Claude가 수행

## 5. 게이트 판정 — ★통과 (2026-09-07 계산 완료)

파일 2개 수령 후 계산 완료. 상세는 `제출자료/2_보고서_재료/웨이브_교차확인.txt`.

- 웨이브 카드소비 60대이상 비중(구군) × 동백전 고령 고객 비중: **스피어만 r = 0.80 (p=0.0002, n=16)**. 상위 4곳 중 3곳(서·영도·중) 겹침. 정체 5곳 전부 웨이브 상위 절반(서 1·영도 2·중 4·사상 6·사하 8위).
- 동백전 가맹점(기준일 2026-04-24): 부산 전역 163,422개, **정체 상권 5곳에 40,274개** — 멤버십 접점 실재.

**보고서 각주 확정 문구 (그대로 사용):**

> (6-1 한계 ③ 보조) 보조 확인: 카드사 소비 데이터(Big-데이터웨이브 「일별 행정동 연령 소비매출 월별 일평균」, 부산광역시)로 구·군별 60대이상 소비금액 비중을 집계하면 동백전 기준 고령 고객 비중과 순위가 강하게 정합한다(스피어만 r=0.80, n=16, 공개데이터 재산출). 고령 소비 축이 동백전 표본만의 산물은 아님을 시사한다. 두 지표는 표본·산출 기준이 달라 수준 비교는 하지 않는다.

> (4-2 보조) 동백전 가맹점 현황(Big-데이터웨이브 개방 데이터, 부산광역시, 기준일 2026-04-24) 기준 가맹점은 부산 전역 약 16만 3천 개이며 정체 상권 5곳에도 약 4만 개가 실재한다 — 제안한 안내 체계의 접점이 이미 깔려 있다.

⚠️ 이 두 각주 외의 위치(특히 3장 분석결과)에는 웨이브 수치를 넣지 않는다.
